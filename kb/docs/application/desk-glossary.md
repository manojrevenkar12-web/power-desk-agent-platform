# Desk glossary

- **Residual load.** Demand minus must-run generation minus wind and solar. When it is negative,
  the zone has a surplus that exports, storage or curtailment must absorb.
- **Price setter.** The block of the supply curve that sets the price in a quarter hour: a gas
  plant, coal, imports, exports and storage, or renewables curtailing.
- **Base, peak, off-peak.** Base is every quarter hour. Peak is 08:00 to 20:00 local time on
  weekdays. Off-peak is everything else.
- **Delivery period.** Always local time. A period given as start and end includes the start day
  and excludes the end day.
- **VPP.** Virtual power plant: flexible assets (batteries, flexible demand) run as one portfolio.
- **REMIT inside information.** Non-public, precise information that would likely move wholesale
  energy prices, such as an unplanned outage before its urgent market message is published.
