# Using the desk agents

The desk agents answer from tools and documents you are allowed to see. Three rules hold for
every answer:

1. Every number comes from a tool result or a document in the same conversation. The platform
   checks each figure before you see it and removes any it cannot trace.
2. You only get data from books you may read. Asking for another desk's book returns a refusal,
   not an approximation.
3. Inside information stays with the people on its insider list. The agents will not confirm,
   deny or hint at it to anyone else.

Developer tools (Claude Code, Copilot) reach market data and documentation, never book data.
